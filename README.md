# The Perceptron and Its Mistake Bound

> **UTS 32513 / 31005 Advanced Data Analytics Algorithms (Machine Learning)** (Spring 2026) · Assignment 2, Option 1: study and implement a fundamental ML model

*"It is guaranteed to stop. Does stopping mean it has learned anything?"*

A study and from-scratch implementation of the Perceptron for binary linear classification, focused on its convergence guarantee (the mistake bound) and what that guarantee does and does not say about generalisation.

- Implemented from scratch with NumPy only (no machine-learning library)
- The notebook generates all of its own data and is fully self-contained
- The journal walks through the problem definition, the training/prediction interfaces, the algorithm, the mistake-bound theory and the experiments
